• +

    add

    Create a file from a template literal. Existing files are skipped unless --force.

  • ~

    insert

    Put a line before a marker comment like # jen:sources, matching its indentation. Idempotent.

  • ~

    modify

    Regex search and replace. Also the way to remove lines.

  • -

    delete

    Remove a file. Stays inside the project root, never touches directories.
