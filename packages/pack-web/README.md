# @codejen/pack-web

A [jen](https://learosema.github.io/jen/) pack for web development: a contrast-checked color palette with light and dark mode, a CUBE CSS starter with fluid type and space, layout compositions, buttons, cards, dialogs, popovers, scroll-driven animations and view transitions – plain HTML and CSS, WCAG AAA by default.

**Documentation: <https://learosema.github.io/jen/web.html>** – every generator with its params, the plan it prints, and live previews.

## Install

```sh
npm install --save-dev @codejen/pack-web   # or: npm install -g @codejen/jen @codejen/pack-web
```

```sh
jen web:cube --primary=#5b5bd6 --dir=src/css
jen web:page --name=index --site="My Site"
```
