# Third-party notices

pack-glsl's own code is MIT No Attribution (MIT-0, see [LICENSE](LICENSE)) and needs no notice. Code by other authors is only included under the MIT license.

Each `.glsl` chunk names its author and source in an attribution line and declares its license with `// @license <id>`: `MIT-0` for the pack's own code, otherwise the id of the full notice in `glsl/licenses/<id>.glsl`. When jen inserts a third-party chunk into a shader, that notice is inserted with it (once per shader).

Each author below gets their own section: source, license id, the chunks taken from them, and their full license notice.

No third-party code is included yet.
